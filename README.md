# Монитор Рунета

Одностраничное табло проверки доступности 16 популярных сайтов: поиск, фильтры по категориям, время ответа и автообновление раз в 2 минуты.

## Запуск
Откройте `index.html` в браузере и нажмите **«Проверить сейчас»**. Проверка использует внешний прокси AllOrigins; доступность прокси и ограничения сайтов могут влиять на результат.

## Ограничения
Это не проверка из российской сети. Ответ прокси не доказывает доступность сайта у каждого российского провайдера, а ошибка проверки не доказывает блокировку. Для надёжного мониторинга нужны серверные проверки из нескольких российских регионов.

## GitHub Pages
В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните. После публикации сайт появится по адресу `https://krivonosarseniy11-source.github.io/R/`.
